# App Store / Google Play Compliance Matrix (living document)

Sensitive features stay behind feature flags (`caller_id_*`, `call_recording`, `voip`, `live_translation`) that default OFF except live translation. Nothing here is legal advice; each row must be re-verified against current Apple/Google policy before a release that enables it.

| Feature                           | Permission                | Purpose string (user-facing)                             | Disclosure / consent                                         | Storage & retention                                                      | Android policy notes                                                                                 | iOS policy notes                                 | Risk               |
| --------------------------------- | ------------------------- | -------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------ | ------------------ |
| Text translation                  | none                      | —                                                        | Privacy policy                                               | Opt-in history; deletable per item / all; no-history mode                | Data safety form: text sent to server                                                                | Privacy nutrition label: user content            | Low                |
| Face-to-face / live subtitles     | Microphone (contextual)   | "Voxeli listens so it can translate what is being said." | Always-visible mic indicator; transient processing statement | Audio not stored unless explicit recording workflow                      | RECORD_AUDIO runtime permission                                                                      | NSMicrophoneUsageDescription                     | Medium             |
