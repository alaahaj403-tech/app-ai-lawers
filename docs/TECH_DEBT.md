# Technical Debt Register

| #   | Issue                                                                                                                                     | Reason                                                                | Risk                                                                             | Remediation                                                                                                         | Priority                     |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| 1   | Realtime minutes are charged from the client's end-of-session report                                                                      | No server media path yet (Tier 1 connects device ↔ provider directly) | Under-reporting by a modified client; cost leakage                               | Reserve minutes at session start with a hard TTL; reconcile with provider usage; move Tier 2 through a server relay | P1                           |
| 2   | Language registry duplicated in Dart (`apps/mobile/lib/shared/languages.dart`)                                                            | Dart cannot import TS                                                 | Drift between platforms                                                          | Generate both from `packages/domain/languages.json` via a script + CI check                                         | P2                           |
| 3   | Tier 1 target-language support is assumed for all registry languages                                                                      | Provider docs do not enumerate supported targets                      | Users may get a degraded session unexpectedly                                    | Runtime capability probe on boot + persisted `provider_health`/capabilities table                                   | P1                           |
| 4   | Model prices absent → cost estimates `null`                                                                                               | Not captured from a verified source yet                               | FinOps dashboards blind                                                          | Add verified price table to admin config; unit test estimator                                                       | P2                           |
| 5   | No email verification / password reset / social sign-in                                                                                   | Milestone 0 scope                                                     | Account recovery gaps                                                            | Add verification tokens table + email provider adapter                                                              | P1 before public launch      |
| 6   | Web "Listen" uses browser SpeechSynthesis, not the server TTS slot                                                                        | Fastest path for Journey B on web                                     | Voice quality varies by browser                                                  | Add `/v1/speech` streaming TTS endpoint (PCM/WAV) and use it on web + mobile                                        | P2                           |
| 7   | Flutter `intl` pinned to 0.20.x by Flutter SDK constraints                                                                                | Flutter 3.47 l10n tooling                                             | None functional; upgrade blocked upstream                                        | Track Flutter release notes                                                                                         | P3                           |
| 8   | pnpm `onlyBuiltDependencies` approves `argon2` and `esbuild` build scripts                                                                | Native/optimised binaries                                             | Supply-chain surface                                                             | Pin versions; review on each bump                                                                                   | P3                           |
| 9   | Android `compileSdk` pinned to 37 because `flutter_secure_storage` 11 compiles against API 37 (canary SDK channel at the time of writing) | Plugin requirement                                                    | CI runners need the 37 platform; canary platforms change                         | Drop the pin once API 37 reaches the stable channel or the plugin relaxes it                                        | P3                           |

| 12  | Mobile `Listen` downloads the whole clip before playing                                                                                   | `audioplayers` BytesSource has no streaming input                     | First audio arrives later than necessary on long texts                           | Stream PCM chunks (`/v1/speech` supports `pcm`) into a streaming player                                             | P3                           |
